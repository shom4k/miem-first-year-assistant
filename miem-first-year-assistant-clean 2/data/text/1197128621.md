## Аннотация
Проектный семинар входит в модуль «Научно-исследовательский и проектный семинар» и проводится на 1 курсе в модулях 3–4. Его цель — формирование базовых знаний, навыков и умений, необходимых для дальнейшей подготовки по направлениям  «Инженер DevOps», «BI-аналитик / аналитик данных» и «Руководитель группы разработки», в частности, формирование таких компетенций, как ПК-3, ДИ-1, АД-1, РГ-1, ППК-Р1, ППК-Р4, ППК-ДА1 и др. в соответствии с ЦКМВ . Образование в рамках курса предполагает знакомство с полным циклом работ по разработке информационно-аналитического ПО. В частности,  освоение базовых методов предварительной обработки данных и построения прикладных моделей, а также переноса полученных результатов в ПО с возможностью визуализации по желанию пользователя. . Проектный семинар — ключевой элемент программы уровня ТОП ИТ «ПРО»: он позволяет использовать знания, полученные в учебном курсе «Информатика», для организации  командной проектной работы по созданию информационно-аналитического ПО уже на первом курсе. Вся аудиторная работа отведена проектной деятельности; лекции не предусмотрены. В реализации курса используются реальные данные, в частности, предоставленные партнерами программы в рамках индустриальных кейсов. В рамках курса слушатели познакомятся с такими важными для создания ПО концепциями, как Git (современная распределенная система контроля версий),  DVC (Data Version Control  управление версиями данных данных),  Docker (платформа контейнеризации, позволяет упаковать приложение вместе со всеми зависимостями в изолированную среду — контейнер), CI/CD (Continuous Integration (непрерывная интеграция), Continuous Delivery / Continuous Deployment (непрерывная доставка / непрерывное развертывание)) и другими, которые будут предложены партнерами програмы. Успешное освоение курса позволит слушателям в дальнейшем участвовать в проектах по созданию ПО категории MVP (Minimum Viable Product — продукт, обладающий минимальными, но достаточными для удовлетворения первых потребителей функциями. Основная задача продукта — получение обратной связи в формате проверки гипотез для формирования стратегии развития продукта). Курс завершается презентацией итогового проекта создания информационно-аналитического ПО, которое использует изученные в курсе технологии. Пререквизитами  семинара являются курс «Информатика», владение грамматикой Python и базовым стеком библиотек для анализа данных на платформе Python (Numpy, Pandas, Matplotlib), знаниями основ теории вероятностей и математической статистики. Постреквизитами — «Операционные системы», «Программирование веб-сервисов», ПС «Инструментальные средства программирования», НИС «Искусственный интеллект в инженерном образовании» и «Разработка мобильных приложений».

## Элементы контроля
неблокирующий Работа на семинарах Выполнение заданий на семинарах. Реализуется в двух форматах:  задача на семинаре (выдается в конце семинара на десять - пятнадцать минут, оценка от нуля до трех баллов), контрольная работа (выдается на 45 минут, оценка от нуля до десяти баллов).

Для указанных контрольных мероприятий пересдача не предусмотрена ни по какой причине
блокирующий Самостоятельная работа Задание для самостоятельной работы выдается на группу из не более, чем трех студентов, один из которых назначается ее Директором. Сутью задания является создание программного продукта с использованием языка Python 3 и изучаемых в курсе библиотек, текущих на момент выдачи задания версий. Использование дополнительных библиотек не разрешено. Задание оформлено в виде документа «Описание проекта», в котором зафиксированы описание функциональных свойств продукта и минимальные требования к его реализации, а также критерии оценивания.
В отдельных случаях, при наличии у студента знаний в области разработки приложений на языке Python и по согласованию с преподавателем, студент может выполнить задание по индивидуальному техническому заданию повышенной сложности. В этом случае оценка за курс (промежуточная аттестация) проставляется по результатам оценивания его проекта.
неблокирующий Итоговое тестирование Используется тест с вопросами, имеющими один вариант правильного ответа и несколько неверных альтернатив. Время выполнения теста строго ограничено. Необходимо представить ответы строго до окончания теста. В противном случае, ответ может поступить в период закрытия теста и не будет зафиксирован. В этом случае считается, что студент не прошел тест.
При прохождении теста не разрешается пользоваться никакими вспомогательными материалами, в частности размещенными в сети Интернет.
