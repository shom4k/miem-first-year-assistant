# Помощник первокурсника ИВТ МИЭМ

Работающий локальный прототип по программам дисциплин 1 курса **2026/2027**. Python + Streamlit. Принимает свободный вопрос на русском, находит фрагменты программ, формирует короткий ответ и показывает ссылки на разделы первоисточников. **Без API-ключей, внешней LLM и сетевых запросов во время ответа.**

## Быстрый запуск

Рекомендуется Python 3.11 или 3.12. Также проверено на Python 3.9.6 / macOS ARM64.

```bash
git clone https://github.com/shom4k/miem-first-year-assistant.git
cd miem-first-year-assistant
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Windows: вместо `source .venv/bin/activate` выполните `.venv\Scripts\activate` (cmd) или `.venv\Scripts\Activate.ps1` (PowerShell). Откройте адрес, который напечатает Streamlit, обычно http://localhost:8501. Исходные документы уже включены: скачивать их для запуска не нужно. Интернет нужен только для установки зависимостей и открытия ссылок ВШЭ.

`requirements.lock.txt` фиксирует точные версии проверенного окружения Python 3.9. Для других версий Python используйте `requirements.txt`.

## Что попробовать

- Какая формула оценки по алгебре и геометрии во 2 модуле?
- Какую литературу рекомендуют по дискретной математике?
- Какие темы изучают в информатике?
- Где изучают комплексные числа?
- С какими дисциплинами связана алгебра и геометрия?

Название дисциплины можно выбрать слева. Углубленные и индустриальные варианты хранятся отдельно. История видна в интерфейсе, но каждый вопрос обрабатывается самостоятельно: местоимения «она» и «этот курс» не используют контекст предыдущего ответа. Ответы можно скачать в JSON.

## Данные и происхождение

Источник: [официальный каталог](https://www.hse.ru/ba/isct/courses?course=1.1.1.4&page=1&year=2026), включая вторую страницу. Снимок от 22 октября 2026 года: **25 из 25 обнаруженных программ**, ошибок скачивания нет. Скрипт проверяет год `2026/2027` и наличие `1-й курс` в карточке. В корпус входят обычные, углубленные и индустриальные варианты, а также экзамены и проектные семинары.

- `data/raw/` — сохраненные публичные HTML-страницы.
- `data/text/` — читаемые программы в Markdown.
- `data/courses.json` — структурированные разделы.
- `data/manifest.json` — страницы каталога, дата сбора, охват и SHA-256.

В некоторых программах есть сведения сразу о 1–2 курсах. **Формулы за 2027/2028 отфильтрованы**, но содержание таких программ не разделено источником по годам: весь список тем нельзя считать календарным планом только первого курса. Это ограничение явно сохраняется.

Формулы и литература воспроизводятся по опубликованным страницам. Пример дефекта первоисточника: сумма весов в формуле математического анализа за 2 модуль равна 0.85, физкультуры за 4 модуль — 0.5. Помощник предупреждает и не дописывает недостающие коэффициенты. Повторяющиеся названия элементов также сохраняются.

```bash
python scripts/collect.py           # обновить снимок с сайта
python scripts/collect.py --offline # повторно разобрать сохраненный HTML
```

При обновлении сайта структура HTML может измениться. Проверяйте manifest и заново запускайте тесты. Скрипт завершится ошибкой при неудачном скачивании хотя бы одной программы.

## Как работает решение

1. BeautifulSoup извлекает разделы программы, исключая меню и оформление сайта. Английские заголовки нормализуются, текст сохраняется на языке оригинала.
2. Разделы делятся по пунктам примерно на 1400 символов. Формулы остаются целыми. Каждый фрагмент хранит курс, раздел и URL с якорем.
3. Поиск объединяет TF-IDF по русским основам слов (Snowball) и символьным n-граммам 3–5: веса 0.65 и 0.35. Символы помогают при вариантах написания, но не обеспечивают семантический поиск.
4. Название курса и тип вопроса ограничивают поиск: оценка, литература, темы, контроль, результаты, метаданные. Для связей берутся явные указания аннотаций и целей.
5. Ответ состоит из коротких выдержек с номерами источников. Полный найденный фрагмент можно раскрыть. Для формул проверяется сумма весов.

Это **retrieval + extractive QA**, а не генеративный RAG. Выбор сделан ради воспроизводимости, запуска без ключа и точного сохранения формул за ограниченное время. Свободное объяснение, расчет и полноценное сравнение программ требуют следующей итерации. Порог релевантности 0.11 — эвристика, не вероятность правильности.

## Известные ограничения

- Нет LLM: не объясняет доказательства, не решает задачи и не дает полноценный синтез нескольких документов.
- Поиск по словам может вернуть близкий, но не отвечающий на вопрос фрагмент. Особенно при вопросах со скрытой предпосылкой и названием курса.
- Литература в кратком ответе ограничена несколькими позициями. Полный список — в программе и раскрываемых фрагментах.
- Расчет оценки, правила округления, блокирующие условия и пересдачи не выводятся из одной формулы.
- Английские вопросы к русским программам и неочевидные сокращения обрабатываются слабо.
- Источник может содержать ошибки, общий текст для нескольких курсов и неполные сведения. Обновление выполняется вручную.
- Встроенные правила отказа — простая эвристика. Они не обеспечивают универсальную классификацию любых вопросов.
- История чата не является контекстной памятью.

## Что улучшить за два дня

**День 1:** ручная сверка многолетних программ и формул, нормализация элементов контроля, отдельная структура модулей, семантический поиск с локальными embeddings и reranker. Расширение независимого набора вопросов, особенно отрицательных и неоднозначных.

**День 2:** опциональная LLM для короткого синтеза только по найденному контексту, проверка соответствия цитат, сравнение двух курсов, уточняющие вопросы, калькулятор оценок с подтвержденными правилами. Повторная оценка качества и задержки, контейнер и публичный демостенд.
